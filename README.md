# 闪亮的 uu · 提示词仓库

在线入口：[打开「闪亮的 uu 提示词仓库」](https://uu525.github.io/shining-uu-prompt-library/)

这里会逐步收录项目提示词与创作资料。目前包含「今天你是什么宝石？」三消和「今日星轨·星光捕捉」两份小游戏提示词包。

## 如何使用

1. 打开上方在线入口，在项目卡片里选择「打开提示词包」。
2. 按页面顶部「怎么用」的步骤准备一个空白文件夹，并在 Codex 中打开。
3. 在线阅读提示词，点击「复制主提示词」交给 Codex；需要继续细化时，再复制对应的迭代提示词。
4. 也可以点击「下载提示词包」保存 Markdown 文件。

当前项目：

- `gem-match.html`：75 秒宝石三消与今日能量报告。
- `today-star-orbit.html`：35 秒星光捕捉、今日星轨与分享星签。

页面为原生 HTML、CSS、JavaScript，无需安装依赖或构建。
