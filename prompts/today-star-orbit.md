# 从零复现「今日星轨·星光捕捉」｜Codex 提示词包

这套提示词面向没有原项目的新用户。打开 Codex 的空白工作区，先粘贴「主提示词」；Codex 会从零创建小游戏。之后按需要继续粘贴视觉、手感、报告卡和问题修正提示词。无需原游戏文件、旧素材、服务端或账号。

## 使用方式

1. 在 Codex 中打开一个空白文件夹。
2. 粘贴下面的「主提示词」，让 Codex 直接创建并完成游戏。
3. 打开生成的 `index.html` 试玩；每次只针对一类问题使用一条迭代提示词。

## 主提示词：从空白开始搭出完整游戏

```text
请从零制作一款叫「今日星轨·星光捕捉」的移动端 HTML 小游戏。把完整项目直接创建在当前空白工作区，完成后给我可立即打开试玩的页面。不要依赖、要求或扫描任何已有项目、目录说明、旧代码或外部素材；不要只给方案或代码片段，也不要等我确认，按下面的默认设定直接实现。

【技术与交付】
- 使用原生 HTML、CSS、JavaScript；不使用 React、构建工具、CDN、后端、联网接口、登录或第三方依赖。
- 生成 `index.html`、`styles.css`、`app.js` 和本地 `assets/` 素材，使用普通 script 标签加载，双击 HTML 即可试玩。
- 所有得分、星体图鉴、隐藏组合与最佳成绩只保存在浏览器本地 localStorage；无法存储时游戏仍可玩。
- 手机竖屏优先，以 390×844 为主，兼容 320–480px，并在桌面端居中展示；尊重刘海安全区和系统减少动态效果设置。

【游戏概念与流程】
- 玩家要在约 35 秒内进行三轮星光捕捉。每轮 9 秒，有 7 颗星体沿圆形轨道绕行。
- 轨道顶部有清楚的金色「最佳捕捉点」。看准星体经过时轻点；也可以把星体拖到中央能量区捕捉。点错时仍有基础分，不出现失败页。
- 如果一轮计时结束玩家没有操作，自动捕捉当前距离最佳点最近的星体，保障每局都能完成。
- 每次捕捉后显示星等和得分，并进入下一轮；三轮分别记录主星光、辅助星、行动星。第三次捕捉后播放短暂星轨揭晓动画，再展示报告卡。
- 一局约 35 秒，无失败惩罚。重新开始时更换星体组合；轮次中的稀有星出现机会逐步提高。

【精准捕捉、计分和连击】
- 根据被点星体当前角度与金色最佳点的圆周角度差判定。
- 角度差不超过 0.18 弧度为「虹光」+100；不超过 0.42 弧度为「明光」+70；其他点击为「微光」+40。
- 虹光或明光算一次精准捕捉并增加连续次数；连续第 2 次精准捕捉额外 +20，连续第 3 次及以后每次额外 +40；微光会中断连击。
- 每次反馈要立刻、清楚地显示「虹光 +100」「明光 +70」「星光连击 ×N」等短字，并同步更新总分。计时、判定和分数不能依赖动画结束时间。
- 玩家拖动时让星体跟手；只有释放在中央能量区内才触发捕捉，拖到其他地方则星体平滑返回轨道。

【14 种星体】
请创建统一风格、可识别、名字准确的 14 种星体；每种都要有展示名、分类 category、色系 family、颜色、稀有度、身份 identity、关键词 keyword、微行动 action 和本地素材：
1. 金色五角星：star / gold / 普通
2. 紫晶四角星：star / violet / 普通
3. 晨星：star / blue / 普通
4. 暮星：star / pink / 普通
5. 新月：moon / violet / 普通
6. 满月：moon / gold / 普通
7. 环形星球：planet / blue / 普通
8. 糖果星球：planet / pink / 普通
9. 彗星：meteor / blue / 普通
10. 陨石：meteor / pink / 普通
11. 流星：meteor / gold / 普通
12. 极光星：wonder / prism / 稀有
13. 星团：wonder / prism / 稀有
14. 星云：wonder / prism / 稀有

每轮先从普通星体中抽取 7 种；第一、二、三轮稀有替换机会分别约为 7%、16%、26%。每三局至少保证第三轮出现一颗稀有星，避免玩家一直遇不到。

如果当前 Codex 环境能生成图像，为 14 种星体生成同一画风的独立透明 PNG；逐张检查透明通道，透明区域不能烘焙白底、灰底、棋盘格或方形光晕。如果没有图像生成功能，制作本地 SVG 星体素材。星体要精致、发光、有体积感；不能用 emoji、粗糙字符或空白占位符。

【5 条隐藏星轨组合】
玩家捕捉的三种星体按以下规则组合；命中具体组合时优先采用具体组合，再检查通用组合：
- 同时有新月和满月：双月相逢｜月相守护者｜关键词「温柔流转」｜微行动：结束一件旧事，也为一件新事留出位置。
- 同时有环形星球和糖果星球：双星环游｜宇宙旅行家｜关键词「自在前行」｜微行动：为自己选择一条更舒服的行动路线。
- 三束里至少两束属于彗星、陨石、流星：流星雨｜流星追光者｜关键词「好运加速」｜微行动：趁现在，把最想做的事向前推进一步。
- 三束星体的 family 全相同：纯色星愿｜专注许愿家｜关键词「心愿聚焦」｜微行动：今天只选一件最重要的事认真完成。
- 三束星体属于三种不同 category：万象星图｜万象绘星者｜关键词「打开可能」｜微行动：试着把两个看似无关的想法连接起来。

未触发隐藏组合时，以第一轮捕捉的主星 identity、keyword 和 action 作为结果。再按总分评级：S 级为 300 分及以上，A 级为 220–299 分，B 级为 220 分以下。结果由本局实际得分和选择决定，不要随机给与表现无关的身份。

【页面内容和视觉】
- 开始页：品牌「今日星轨」、短钩子「捕捉三束星光，点亮今日星轨」、主视觉星体轨道、开始星光捕捉、星体/隐藏星轨/最佳分数进度、一局约 35 秒和无需登录说明。
- 游戏页：本轮序号、9 秒倒计时和进度条、实时得分、短操作提示、圆形旋转轨道、金色最佳捕捉点、中央能量区，以及三格「主星光 / 辅助星 / 行动星」记录栏。轨道与 HUD、记录栏要有间距，任何手机尺寸都不遮挡星体。
- 揭晓页：三颗已捕捉星体连成一条发光星轨，清楚显示「三束星光正在连成星轨」；提供轻触跳过。
- 结果页：大字展示评级、星轨组合名、今日身份、关键词和一句微行动；显示三颗星体、总分、评级；提供保存报告、分享、看图鉴、再测一次。
- 图鉴页：展示 14 种星体和 5 条隐藏星轨；未解锁的只显示轮廓与提示，不丢失已解锁记录；显示个人最佳分数和已遇见数量。
- 整体视觉采用轻盈的星空编辑设计：雾紫、薰衣草紫、浅蓝、珍珠白，金色用于最佳命中提示；星体用通透的 3D 质感与柔和光晕。文字深色高对比、界面留白充足、圆角玻璃感卡片，不做黑底科幻控制台，不要堆满小字。
- 命中反馈有短促光环、粒子、评分浮字、轻微震动和轻音效；音效可一键关闭。尊重减少动态效果设置，效果不能妨碍下一次操作。

【报告卡和分享】
- 用 Canvas 生成 1242×1656 的 3:4 PNG 星签，包含「今日星轨」品牌与日期、评级、今日身份、三颗星体、隐藏星轨名（如果触发）、关键词、一句微行动、总分和「跟随三次直觉选择，走出今天的星轨 · 娱乐体验」。文字留安全边距，自动换行且不能裁切。
- 页面要提供保存图片、系统分享和复制分享文案；支持 `navigator.share` 时分享图片，否则下载 PNG 并复制文案。取消分享不应显示为程序错误。
- 结果文案表达娱乐与自我觉察，不宣称预测真实命运、健康、财务或未来。

请现在直接创建完整游戏，并亲自走一遍：打开首页、开始游戏、三轮捕捉、自动捕捉、结果揭晓、保存图、重测、图鉴。完成后告诉我入口文件和试玩方式，确保不需要安装依赖。
```

## 迭代提示词 A：让捕捉更跟手、更有命中爽感

```text
请只调整星光捕捉的手感和反馈，不要改变三轮规则、角度判定或分数。

点击应在一瞬间显示虹光/明光/微光和分数；拖动的星体要跟手，中央能量区命中范围要清楚，松手未进区时要顺滑回轨。完美命中时加强金色光环、粒子和短音效，连续命中时突出连击倍率；所有反馈尽量在 500 毫秒内完成，玩家能马上继续。

请按实际 390px 宽手机操作，检查星体点击热区、拖动时是否误触点击、动画期间是否锁死整个游戏。没命中时仍应保留基础分和下一次机会，不出现失败页。
```
