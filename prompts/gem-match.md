# 从零复现「今日能量宝石三消」｜Codex 提示词包

这套提示词面向没有原项目的新用户。打开 Codex 的空白工作区，按顺序复制即可；不需要旧游戏代码、素材、文件清单或网络服务。第一条负责从零搭出可玩的网页，后续提示词负责爽感、视觉、报告卡和细节修正。

## 使用顺序

1. 在 Codex 中打开一个空白文件夹，粘贴「主提示词」，让它直接创建并完成游戏。
2. 打开生成的 `index.html` 试玩。再根据需要，依次粘贴后面的视觉、爽感、报告卡、问题修复提示词。
3. 每轮改完都实际试玩一次；发现问题时，把方括号中的例子换成你看到的具体现象。

## 主提示词：一次搭出能玩的完整版本

```text
请直接从零制作一个叫「今天你是什么宝石？」的移动端 HTML 三消小游戏。把需要的文件创建在当前空白工作区，完成后给我一个可以立即打开试玩的版本。不要依赖或要求我提供任何旧项目、代码、素材、目录说明、账号、服务器或第三方服务；不要只给计划或代码片段，也不要等我确认，按下面的默认方案直接实现。

【产品体验】
这是一个轻松、爽快、适合录屏分享的三消游戏。流程是：精致的开始页 → 3 秒倒数 → 75 秒自由消除 → 宝石觉醒动效 → 今日能量报告 → 保存/分享/重新测。没有关卡、失败惩罚、登录或排行榜。用户的目标是玩得爽，并看到一张有趣、值得晒的结果卡。

【运行方式】
- 使用原生 HTML、CSS、JavaScript，不使用框架、外部 CDN、后端或付费服务。
- 请创建清楚的静态文件结构，例如 `index.html`、`styles.css`、`game.js`、`report.js` 和 `assets/`；必须不经构建就能运行。
- 所有图片和音效都在本地。优先让 `index.html` 双击可玩；若浏览器限制某项能力，页面内要有说明和替代方案。
- 做完后实际检查开始、试玩、结束、保存和重测这条完整路径，并告诉我打开方式。

【核心玩法】
- 7×7 棋盘，六种宝石可以通过触摸拖动或点击相邻两颗来交换；只允许上下左右相邻交换。无效交换会弹回并给出轻反馈。
- 连成横向或纵向三个及以上同色宝石即可消除；消除后重力下落、补充新宝石，并自动处理连续连锁。
- 新局棋盘不能有自动三连，必须至少存在一步合法移动；无路可走时自动洗牌。提供轻量提示，不要挡住操作。
- 计时严格为 75 秒。剩余时间到零自动结束；切到后台时暂停并显示继续按钮，不偷走玩家时间。暂停按钮和音效按钮都要可用。
- 游戏过程中展示倒计时、进度条、六项能量和棋盘。棋盘与顶部 HUD 之间留出明显空间，底部提示不能挤压棋盘；任何手机尺寸都要显示完整七行。

【六种宝石与能量】
- 玫瑰晶＝桃花；黄水晶＝财运；蓝宝石＝事业；祖母绿＝好运；紫水晶＝松弛；红宝石＝行动力。
- 普通消除的每颗宝石，为对应能量加 1。
- 四连生成横/竖光束，并额外增加 6 点对应能量。
- T/L 形生成范围炸弹，并额外增加 8 点对应能量。
- 五连直线生成彩虹宝石，并使六项能量各增加 5 点。
- 连锁倍率依次提升为 1、1.25、1.5、1.75，最高 2 倍；按实际被清除的宝石颜色累计能量。特殊宝石触发时要继续清除并可引发连锁。
- 轻度提高新手遇到特殊形状和自然连锁的机会，让一局中能看到爽点；不要用无法理解的随机奖励替代真实消除。

【特效与手感】
- 普通消除要干净利落；四连有扫过整行/列的光束，T/L 有冲击波，五连有彩虹全屏闪耀，连锁时显示醒目的「连锁 ×2 / 能量暴涨」短字并有宝石飞入能量栏。
- 交换有短暂拖尾或弹性，落子有节奏，炸开时棋盘轻震。效果明显但不拖慢连续操作。
- 可用浏览器 Web Audio 合成轻音效；支持时提供轻振动。浏览器不支持时游戏仍可玩。尊重系统减少动态效果设置。

【现代宝石视觉】
- 整体采用精致的小红书生活方式视觉：奶油白底色、雾粉/淡紫/香槟金渐变、深葡萄色文字，明亮、轻盈、像一款愿意截图分享的小游戏。
- 六颗宝石要颜色区分清楚、晶莹通透、有真实切面折射和柔和高光；整体造型现代、简洁、成套，不要儿童卡通、厚重描边、廉价塑料光、花哨皇冠或过多装饰。
- 宝石本体不要放汉字、数字、emoji 或大号字母。不要用普通 emoji 代替宝石。
- 如果当前环境可生成图片，就生成六张风格一致、真正透明背景的独立宝石 PNG；检查 PNG 的 alpha 通道，透明区域不能带白底、棋盘格、灰边或光晕方框。如果没有图像生成能力，画成边缘干净、带多层切面的 SVG 宝石，作为透明素材使用。
- 页面使用圆角玻璃卡片、克制的阴影和细腻渐变。优先用留白和排版建立质感，不要把每块区域都塞满边框和文字。

【结果与报告卡】
- 报告由本局实际收集的六种能量决定主宝石与副能量；使用日期和本局种子做轻微 ±8% 微扰，让重测有变化，但不能完全违背本局表现。
- 为桃花、财运、事业、好运、松弛、行动力分别给出 1–5 星；最强项为 5 星。内耗指数按「6－松弛星级」计算。
- 每颗主宝石准备多套短标题、今日金句、建议和避雷提醒；另给幸运颜色和一个轻松的小行动。文案要像朋友的嘴替，轻玄学、俏皮、不吓人，不宣称真实预测。
- 结果页信息要少而醒目：日期、主宝石、主能量、六维六边形雷达图、内耗指数、一句金句、幸运颜色/行动。标题和宝石名最大，避免密密麻麻小字。
- 结果分享图使用 Canvas 输出 3:4 竖图，尺寸 1242×1656，边距充足、文字不裁切、手机上清晰；提供保存 PNG、系统分享（浏览器支持时）和复制分享文案的兜底。
- 报告图文案包括「来测测你今天是什么宝石」和「娱乐体验，不构成现实建议」。不要把分享作为重测门槛。

【尺寸和质量要求】
- 以 390×844 手机竖屏设计，并兼容 320–480px；桌面端居中展示，不横向溢出。
- 使用安全区适配刘海屏；棋盘要完整，最后一行必须露出；倒计时、能量条、游戏棋盘互不遮挡。
- 开始按钮必须真实启动游戏，不允许点了没反应。保存失败或图片素材加载失败时给出可理解的兜底，不要白屏。
- 不采集个人信息；只用本地数据。提供重新测一次按钮。

请现在直接创建并实现完整游戏。完成后简要告诉我：入口文件、怎么玩、报告卡如何保存，以及你实际检查过哪些关键尺寸和交互。
```

## 迭代提示词 A：把消除做得更爽

```text
请基于现有游戏，只增强消除反馈和连锁爽感，不要改坏三消规则或报告算法。

我要的感觉是：玩家一眼看出自己消掉了多少、连了几次、能量涨了多少。优化宝石交换的跟手感、下落节奏、四连光束、T/L 炸弹冲击波、五连彩虹闪光、连锁大字和能量飞入 HUD。特效要亮、快、干脆，动作之间留一点呼吸，不要满屏持续闪烁。

新手偶尔连续几步都没有特殊效果时，可以温和增加补位形成自然连锁的概率，并加强提示；不要直接送大量虚假能量。请在改完后亲自试玩一局，确认特效没有挡住棋盘、按钮或倒计时。
```

## 迭代提示词 B：把宝石和页面做得更高级

```text
请重做现有视觉系统，不要只在原页面上继续叠装饰。整体要像现代的小红书趣味测试：奶油白、雾粉、淡紫和香槟金的高级渐变，清楚的字体层级，大留白、柔和玻璃卡片。

宝石要有统一造型和晶莹切面，颜色区分桃花粉、蜂蜜金、海盐蓝、祖母绿、柔雾紫、石榴红。不要在宝石中间写「桃、财、业、运、松、能」等大字；不要回到繁复卡通宝石，也不要退化成几何色块或塑料圆球。宝石外侧必须是真透明，不要出现方形底、灰边或白色污染。

请把开始页、HUD、棋盘、弹窗和报告卡一起统一调整。展示时优先保证游戏区域清楚、宝石好看、文字易读，装饰做减法。不要改玩法。
```

## 迭代提示词 D：检查开始按钮、旧素材与透明通道

```text
请按手机用户路径实测并修复这些细节：
1. 点击「开始测试」后必须进入 3 秒倒数和游戏，检查按钮是否被遮罩、事件是否重复绑定。
2. 逐个检查棋盘使用的六颗宝石是不是同一套最新素材，清掉页面引用中的旧版图片或错误缓存路径；新素材加载失败时应有干净的 SVG 兜底。
3. 检查 PNG 的 alpha 通道和实际页面合成效果，确认透明边没有白框、灰底、残留背景色或方形光晕。
4. 棋盘必须与顶部 HUD 留有明显间距，底部第七行完全可见。

请告诉我每个问题的原因和修复位置，然后实际点击开始、交换宝石、暂停/继续并截屏确认；不要只回复“已修复”。
```

## 迭代提示词 E：把报告做成值得晒的卡片

```text
请重新整理结束页和导出的结果卡。用户第一眼只需要看到：今天的主宝石是什么、主能量是什么、六项能量各几星、今天的一句嘴替。把六项能量做成清晰的六边形雷达图，并用小字补充内耗、幸运色和行动提示。删掉长段解释。

结果卡是 3:4 竖图，Canvas 输出 1242×1656 PNG。主宝石与标题要醒目，文字在手机上能读，底部留安全边距。请检查 PNG 实际下载后能打开，边缘无裁切、背景无污染；分享 API 不支持时仍能下载并复制文案。页面内的结果卡预览和保存图内容要一致。
```

## 这套提示词覆盖了什么

- 从空白开始生成纯 HTML 三消游戏，不依赖他人项目或素材。
- 7×7、75 秒、六维能量、特殊宝石、连锁与能量报告的完整玩法。
- 奶油粉紫高级渐变、通透切面宝石、强反馈特效和分享卡视觉。
- 生成后继续处理真实试玩中的按钮、空间、裁切、旧素材和透明通道问题。

核心方法不是反复说“做漂亮一点”，而是讲出看见的现象、预期效果和不能破坏的功能，再把修改后的版本重新玩一遍。
